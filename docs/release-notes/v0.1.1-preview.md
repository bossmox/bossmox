BossMox 0.1.1 preview: it now tells you when there's a new version, and it stops nagging about backups you already make another way.

**Update** as root on the Proxmox node that holds the BossMox VM. Your settings stay, and if the new version doesn't start, the old one comes back:

```sh
bash -c "$(curl -fsSL https://github.com/bossmox/bossmox/releases/latest/download/update-bossmox.sh)"
```

On 0.1.0 you need to run that once. From 0.1.1 on, BossMox tells you when an update is out.

**New**

- **Update notices.** Every 6 hours BossMox asks GitHub whether a newer version is out. If one is, it shows on the desktop and in the health check, with the command to copy and a link to what changed. It never installs anything by itself. Each check tells GitHub this BossMox's internet address, so you can turn it off in the health check.
- **"We back up another way."** If Veeam, a script or another backup server protects your guests, one switch stops the "isn't on a backup schedule" warnings for the whole cluster. Failed Proxmox backups are still reported, and the health check shows the schedule check as turned off, never as passed.

**Under the hood**

- TypeScript 7, version 6 of the terminal used for consoles, and newer type definitions, each tested on a real cluster before merging.
