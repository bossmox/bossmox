The first public preview of BossMox: a desktop in your browser for running Proxmox VE, in plain English.

**Install** as root on a Proxmox node:

```sh
bash -c "$(curl -fsSL https://github.com/bossmox/bossmox/releases/latest/download/install.sh)"
```

It asks before doing anything, makes one small VM and changes nothing else. Then open the address it prints, check the certificate fingerprint, and enter the setup code.

**What's in it**

- Guests: make, start, stop, console, settings, disks, network cards, snapshots, clones, templates, moves and deletes.
- Storage shown as drives and the pools on them, guided Add storage, what's on each pool, and safe clean-up of leftovers.
- Backups: protect everything in one step, back up now, restore, and a warning when backups would sit beside the guests.
- Nodes: one-click free update channel, updates in a live terminal, rolling cluster updates.
- A health check with the fix for each problem.
- A setup wizard that can build a cluster.
- Three looks: Daylight, Dusk and Workbench.

**This is a preview.** Tested on Proxmox VE 9.2, on a single node and a three-node cluster. Coming next: iSCSI, usage graphs, alerts, USB passthrough, safe address changes, adding nodes and a tie-breaker, and high availability. Proxmox's own interface keeps working alongside it.

**Security.** An independent review of everything in this release found no critical or high issues; the two medium and eight of the nine low findings are fixed, and the open one (signed release files) is planned. Each download is checked against its SHA-256 checksum. Please report problems privately through the Security tab.

**How it's built.** Rocky Lott directs BossMox and Claude, an AI model from Anthropic, writes much of the code. It isn't vibe-coded: every feature starts with a written decision record, is tested on a real Proxmox cluster before release, and is covered by automated tests that are proven able to fail. The details are in the README's "How it's built".
