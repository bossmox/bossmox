BossMox 0.1.6 preview: eject every disc first, then check once.

**Update** with Update now in BossMox, or as root on the Proxmox node that holds the BossMox VM:

```sh
bash -c "$(curl -fsSL https://github.com/bossmox/bossmox/releases/latest/download/update-bossmox.sh)"
```

**Changed**

- **Not ready to update stays put while you eject.** In 0.1.5 each Eject checked every node for updates again. Now Eject marks the VM "Disc ejected" right there, **Eject all** takes every listed disc out with one confirmation, and **Check again** runs the full check once, when you're done.
