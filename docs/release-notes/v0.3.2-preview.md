BossMox 0.3.2 preview: help where you need it, and every option in BossMox. (Draft: filled in as each piece is built.)

**Update** with Update now in BossMox, or as root on the Proxmox node that holds the BossMox VM:

```sh
bash -c "$(curl -fsSL https://github.com/bossmox/bossmox/releases/latest/download/update-bossmox.sh)"
```

Upgrading a real cluster from Proxmox VE 8.4 to 9 with BossMox worked, but left too much guessing. This release explains, shows progress, and keeps you inside BossMox. ([#110](https://github.com/bossmox/bossmox/issues/110), [ADR 0044](https://github.com/bossmox/bossmox/blob/main/docs/adr/0044-help-and-every-option.md))
