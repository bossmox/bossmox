BossMox 0.1.4 preview: check for a new BossMox whenever you like.

**Update** with Update now in BossMox, or as root on the Proxmox node that holds the BossMox VM:

```sh
bash -c "$(curl -fsSL https://github.com/bossmox/bossmox/releases/latest/download/update-bossmox.sh)"
```

**New**

- **Check now.** The health check's BossMox line has a Check now button, also before the first automatic check has run. It asks GitHub straight away; if a newer version is out, it says so and opens How to update. It checks at most once a minute, however often it's pressed.

0.1.3, released earlier today, moves guests only where they fit and remembers where they live. If you're on 0.1.2, this update brings both.
