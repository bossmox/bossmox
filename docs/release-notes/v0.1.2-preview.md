BossMox 0.1.2 preview: update from inside BossMox, usage graphs, and desktop icons you can arrange.

**Update** from the notice BossMox shows (on 0.1.1), or as root on the Proxmox node that holds the BossMox VM:

```sh
bash -c "$(curl -fsSL https://github.com/bossmox/bossmox/releases/latest/download/update-bossmox.sh)"
```

**New**

- **Update now.** When a new version is out, the update window's Update now button opens the node's console inside BossMox with the update command typed in. Press Enter, answer y, and BossMox restarts on the new version. If the new version doesn't start, the old one comes back.
- **Usage graphs.** A node's Overview shows processor, memory and network over the last hour, day or week; a guest's adds disk activity. Hover for the exact values. The history is Proxmox's own, so it's there from the start.
- **Arrange the desktop.** Drag icons anywhere on the desktop. They snap into place, swap when dropped on each other, and stay where you put them in that browser. Right-click the desktop to line them up again.
- **A fixed address at install.** Run by hand, the installer asks for BossMox's address, with the gateway filled in from the node, and refuses one that's already in use. An automatic address can change after a restart and break your bookmark.
- **Change a container's address.** Fixed or automatic, from the container's network card. The rest of the card stays as it was, and typos are refused with the reason.
