BossMox 0.3.1 preview: VMs and containers, side by side.

**Update** with Update now in BossMox, or as root on the Proxmox node that holds the BossMox VM:

```sh
bash -c "$(curl -fsSL https://github.com/bossmox/bossmox/releases/latest/download/update-bossmox.sh)"
```

BossMox has managed containers from the start, in the same screens as VMs: create from a template, start and stop, console, settings, snapshots, clone, move, back up and restore, and change the address. Until now the home screen only ever said "VM". ([#107](https://github.com/bossmox/bossmox/issues/107), [ADR 0043](https://github.com/bossmox/bossmox/blob/main/docs/adr/0043-vms-and-containers.md))

**New names**

- **VMs and Containers** (was Virtual Machines) and **Create** (was Create a VM).
- Messages that are about both now say so: the home summary, moves and their network, Update and Upgrade all nodes, restores.

**Which is which**

- Each guest in the list has a small icon: a screen for a VM, a box for a container. The detail pane says which it is under the name.
- A container's Technical details (Settings tab) now show its Container ID, instead of a VM's machine type, firmware, disk controller and CPU model.

**Filter and sort**

- Show VMs and containers, VMs only, or Containers only, alongside the node filter, All / Running / Needs a look, and the search.
- Sort by name, type (VMs first, then containers) or node. Names with numbers sort as numbers: web9 comes before web10.
- Your choice is remembered in this browser.
