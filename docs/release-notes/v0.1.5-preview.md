BossMox 0.1.5 preview: every disc drive, and Eject where a disc keeps a VM from moving.

**Update** with Update now in BossMox, or as root on the Proxmox node that holds the BossMox VM:

```sh
bash -c "$(curl -fsSL https://github.com/bossmox/bossmox/releases/latest/download/update-bossmox.sh)"
```

**New**

- **Eject from the Restart and Update all nodes windows.** Proxmox won't move a running VM that holds a disc image from its node's own storage. BossMox already said so; now each such VM gets an Eject button right there. The disc comes out, the VM keeps running, the disc stays on the node, and the plan is drawn again.
- **Every disc drive on the Hardware tab.** A VM's disc drives are listed on any slot, not just the usual one, each with its own Change disc. Before, a disc in another drive showed as Empty.
